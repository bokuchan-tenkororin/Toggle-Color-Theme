　「Toggle Color Theme」は、ウェブページのカラーテーマを補色化するChromeの拡張機能です。  
  
【ウェブページのカラーテーマ】  
　ウェブページの中には、ライトモードのウェブページ、ダークモードのウェブページ、ライトモード／ダークモードの切替ボタン付きのウェブページ、ライトモードとダークモードが混在するウェブページ、カラーテーマが曖昧なウェブページなどがあります。  
　ウェブページをライトモードで表示したい場合や、ダークモードで表示したい場合、あるいは、午前６時から午後６時まではライトモードで表示し、それ以外の時間はダークモードで表示したい場合もあります。  
  
【「Toggle Color Themeの特徴】  
　「Toggle Color Theme」は、ウェブページを補色化することにより、ライトモードのウェブページをダーク化し、ダークモードのウェブページをライト化します。  
  
【Toggle Color Themeのインストール】  
(1) Chromeの拡張機能の「デベロッパーモード」をONに設定します。  
(2) 「パッケージ化されていない拡張機能を読み込む」をクリックします。  
(3) この拡張機能が保存されているフォルダを選択します。  
  
【Toggle Color Themeの使い方】  
(1) この拡張機能のアイコンをクリックすると、ウェブページが補色化されます。これにより、ライトモードのウェブページはダーク化され、ダークモードのウェブページはライト化されます。ウェブページがライト化／ダーク化されると、この拡張機能のアイコンに「ON」が表示されます。ライト化／ダーク化の情報は、ウェブページ毎に保存され、そのウェブページを次に表示したときも、ライト化／ダーク化した状態で表示されます。  
(2) この拡張機能のアイコンを再度クリックすると、ライト化／ダーク化された状態からオリジナルのカラーテーマに戻り、この拡張機能のアイコンから「ON」が消えます。  
(3) ウェブページによっては、ライト化／ダーク化することにより見づらくなる場合があります。  

【オプション画面】  
(1) Chromeの拡張機能の管理画面で「オプション」を開くと、オプション画面が表示されます。  
(2) 「疑似ブックマークの保存フォルダ」で、設定を保存するブックマークフォルダを選択します。オプションの設定一式（保存フォルダの設定を含む）は、選択したフォルダの中に「疑似ブックマーク」として保存されます。ウェブページを開くためのブックマークではなく、あくまでオプションの設定を保存するためのブックマークです。  
(3) 「ON したウェブサイト」には、ツールバーのアイコンで「ON」にしたウェブサイトが一覧表示されます。URLを入力して「追加」を押すと新規登録でき、「削除」を押すとそのウェブサイトだけ登録を解除できます。各ウェブサイトは保存フォルダの中に1件の疑似ブックマークとして保存されます。  
(4) 設定を変更してオプション画面を閉じると、変更した設定が保存フォルダ内の疑似ブックマークとして保存されます。保存フォルダを変更した場合は、閉じたときに変更前の保存フォルダから疑似ブックマークが削除され、変更後の保存フォルダに保存されます（ユーザ自身のブックマークは削除されません）。  
(5) Chromeの起動時に、保存フォルダから疑似ブックマークが読み込まれ、その内容が設定として復元されます。  
  
【画像・動画の保護】  
　この拡張機能は、ページ全体に1回だけ補色化を適用した上で、画像・動画・canvas・SVG・iframe・背景画像などが「補色化の回数が偶数（＝元の色）」になるように自動で補正します。そのため、テーマは補色化（ライト化／ダーク化）されつつ、画像や動画は元の色のまま表示されます。  
　背景画像を持つ大きなコンテナ（body や header など）は、背景を擬似要素レイヤーへ移して保護するため、ページ内のテキストやその他のテーマ色も正しく補色化されたまま保たれます。  
　ページ読み込み後に動的に追加される要素や、Shadow DOM 内の要素も、MutationObserver と定期的な再走査で自動的に保護対象に加えられます。  

【既知の制限】  
　・擬似要素（::before／::after）がサイト側で使用中で背景を移せない場合は、その背景画像だけ補色化されたままになる場合があります。  
　・サイト側がCSSのtransition／animationでfilterを変更している間は、一瞬だけ保護が外れることがありますが、数秒以内に自動で復旧します。  
　・display:none で非表示の要素は、表示された後の再走査（数秒以内）まで保護されない場合があります。  

【まとめ】  
　「Toggle Color Theme」を使えば、ウェブページを補色化してライト化／ダーク化し、好みのカラーテーマで表示することができます。
