　「Toggle Color Theme」は、ウェブページのカラーテーマを補色化するChromeの拡張機能です。  
  
【ウェブページのカラーテーマ】  
　ウェブページの中には、ライトモードのウェブページ、ダークモードのウェブページ、ライトモード／ダークモードの切替ボタン付きのウェブページ、ライトモードとダークモードが混在するウェブページ、カラーテーマが曖昧なウェブページなどがあります。  
　ウェブページをライトモードで表示したい場合や、ダークモードで表示したい場合、あるいは、午前６時から午後６時まではライトモードで表示し、それ以外の時間はダークモードで表示したい場合もあります。  
  
【「Toggle Color Themeの特徴】  
　「Toggle Color Theme」は、ウェブページを補色化することにより、ライトモードのウェブページをダーク化し、ダークモードのウェブページをライト化します。  
  
【Toggle Color Themeのインストール】  
(1) Chromeの拡張機能の「デベロッパーモード」をONに設定します。  
(2) 「パッケージ化されていない拡張機能を読み込む」をクリックします。  
(3) この拡張機能が保存されているフォルダを選択します。  
  
【Toggle Color Themeの使い方】  
(1) この拡張機能のアイコンをクリックすると、ウェブページが補色化されます。これにより、ライトモードのウェブページはダーク化され、ダークモードのウェブページはライト化されます。ウェブページがライト化／ダーク化されると、この拡張機能のアイコンに「ON」が表示されます。ライト化／ダーク化の情報は、ウェブページ毎に保存され、そのウェブページを次に表示したときも、ライト化／ダーク化した状態で表示されます。  
(2) この拡張機能のアイコンを再度クリックすると、ライト化／ダーク化された状態からオリジナルのカラーテーマに戻り、この拡張機能のアイコンから「ON」が消えます。  
(3) ウェブページによっては、ライト化／ダーク化することにより見づらくなる場合があります。  
  
【まとめ】  
　「Toggle Color Theme」を使えば、ウェブページを補色化してライト化／ダーク化し、好みのカラーテーマで表示することができます。
